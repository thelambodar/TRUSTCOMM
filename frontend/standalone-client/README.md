# 🌐 TRUSTCOMM — Standalone HTML5 Client Demonstration

> **Zero-Dependency Browser Client Demonstration**  
> *Standalone HTML5 / ES Modules / WebCrypto API / Canvas Forensics*

---

## 🛡️ Overview

The **Standalone Client** is a lightweight, zero-dependency HTML5/ES6 browser demonstration of the TRUSTCOMM deepfake-resistant provenance and verification system. It allows running client-side cryptographic verification and forensic analysis directly in any standard browser without needing npm build steps.

---

## 🌟 Key Features

- **🔍 Client-Side C2PA Manifest Inspector**: Parses content provenance manifests and verifies SHA-256 digests in-browser.
- **✍️ WebCrypto ECDSA Signing Studio**: Generates ECDSA P-256 keypairs and signs digital notices directly using browser WebCrypto APIs.
- **🔴 Key Revocation Ledger**: Instant local simulation of key revocation effects on verification outcomes (`CREDENTIAL_REVOKED`).
- **🧪 Interactive Forensic Demos**: Preloaded test scenarios for authentic video broadcasts, AI voice clone audio, unsigned documents, and revoked keys.
- **📊 Spectral Audio Canvas Visualizer**: Real-time Web Audio API FFT frequency analysis and audio signal visualizer.
