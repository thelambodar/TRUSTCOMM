# Architecture & Implementation Documentation

## Client Components
1. `app.js`: Main state management and tab routing.
2. `crypto.js`: WebCrypto API integration for SHA-256 and ECDSA signing.
3. `c2pa.js`: JUMBF metadata manifest structure builder.
4. `forensics.js`: Audio FFT spectrum analyzer and video canvas overlay.
5. `blockchain.js`: Simulated blockchain timestamp anchor.
6. `qr.js`: QR code generation helper.
